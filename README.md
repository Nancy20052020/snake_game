# Snake Game

A Snake game written with Python's `turtle` module. The high score is saved in `data.txt`.

## Requirements

- Python 3
- Tk, which `turtle` uses for the window

## Run

```bash
python game.py
```

## Controls

Move the snake with the arrow keys. Eat the food to grow and raise the score. Hitting a wall or the snake's own body ends the run and resets the board. A new high score is written back to `data.txt`.
